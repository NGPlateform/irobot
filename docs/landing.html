核心架构

LLM 只提议，确定性层处置

认知与控制分离成两个环。语言模型可以幻觉、可以慢，但它碰不到执行器——每个写操作都要穿过确定性的安全监督层。

慢环 · 认知

LLM / Orchestrator

NLU 或 LLM 产出声明式动作提案 → 校验、前置条件、安全等级处置、状态机守卫。

→
快环 · 确定性

Edge 安全监督（Rust）

权威准入：幂等、租约 fencing、并发互斥、deadline、急停——独立进程、fail-closed。

→
执行 · 物理

设备 / 仿真

SimRobot（含占据建图 + A* 避障）或真实 TurtleBot 4，流式回传 ActionEvent 与遥测。

硬件急停、碰撞保护与看门狗 不依赖 LLM、Gateway 或互联网。身份、状态、策略或租约不明确时一律 fail-closed。

安全不变量

不可绕过的八条底线

在 TypeScript 慢环与 Rust 快环里各有测试守护（开发计划 §8.2），共 98 个单元/契约测试。

01幂等 · exactly-once

相同 idempotencyKey 重试不产生第二次物理动作。

02租约 fencing

较旧 leaseEpoch 被拒，防止过期控制者抢写。

03concurrencyKey 单写者

同资源互斥；不同资源（导航 + 机械臂）可并行。

04deadline 强制

超时动作进入不可变终态，不悬挂。

05S4 禁止

禁止级动作在桥接层即拒，纵深防御不靠模型。

06不可变终态

SUCCEEDED/FAILED/CANCELLED 落定后不可逆。

07重启可恢复审计

Action Ledger 落 SQLite（WAL），Gateway 重启可恢复。

08每设备单写者

舰队多机各自控制域，跨设备并行、同设备串行。
